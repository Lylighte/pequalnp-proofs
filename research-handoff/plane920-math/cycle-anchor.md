# A cycle-space bound for L-meta-920

In the dual, raw signs record a set of at most four missing points. A distinguished line output accepts only its own four-point row. Simplify constants, duplicate operands and unary copies. Order all raw sources before all gates in a topological order.

For every line L choose once and for all a true sub-DAG D(L) on its row. Choose one true operand at each reached OR consistently; include both at each AND. Every vertex of D(L) is true on L. Every one of the four points of L occurs as a source, since a proof only requires its own leaf labels. No other source and no other selected line terminal occurs in D(L).

Call a proof tree semantically clean if it uses precisely the four distinct points as leaves, allowing a gate certified true on a singleton {p} to stand for a single leaf labelled p. This allowance is sound under upwards grafting because p alone forces the gate true. In such a tree each proper binary branching gate g has a unique globally minimum true input T, the leaf support of its subtree. Indeed if U is any minimum input for g then |U| ≤ |T| and replacing the subtree makes the line output true on U united with the other 4−|T| leaves. The result must equal L, and hence U=T. The three branch supports are distinct and all have size at least two. Consequently their gate identities can be assigned only to L. A terminal of a different line cannot be one of these active gates. This gives m ≥ 39−2b if all but b lines have a semantically clean proof, since the other b terminals are still distinct.

For a fixed D(L), repeat the following operation. If the underlying undirected graph is acyclic, the accepting proof is a tree. Its sources are distinct. Compressed singleton-subproofs below are counted as single leaves, so this is the preceding clean case. Otherwise take the latest vertex t on any undirected cycle. It has two entering edges on that cycle, and is its unique latest vertex. The part of the subproof below t touches its outside only through t. Indeed every gate is directed towards the root; if some vertex below t also had a path to the root avoiding t, take the two paths via t and avoiding t, their last common vertex before t and their first common vertex after t. Two internally disjoint directed paths would form a cycle with an endpoint strictly later than t, contrary to selection. In particular the subset T of source labels below t is disjoint from the outside source labels C, and their union is L. As above, any minimum input U for t yields U=T. Constants have already been removed, so T is nonempty.

If |T|≥2, assign L the anchor t and its cycle. The gate's unique minimum T identifies its line. If |T|=1, replace the subproof by the certified singleton leaf. For graph bookkeeping retain a directed path from its one source to t and discard the remaining vertices and edges below t. Internal vertices of the path serve only to remember original edges and are not counted as logical gates of this reduced proof. The path is disjoint from the outside, so this strictly decreases cycle rank while keeping the original four physical sources. Repeat. Every final anchor is the latest vertex of a cycle of the original D(L), even if earlier deletions have taken place.

More explicitly, a retained path always uses edges of the original D(L), including any edges of paths retained in a previous step. Below t every ordinary gate has an acceptance subproof whose only source is p, so is true on the singleton input {p}; this includes vertices of the retained path. A bookkeeping vertex in an older path is also true on {p}, by the same assertion from the previous step. No internal vertex of the new path, and in particular no second occurrence of its raw source p, belongs to the outside: a directed path from such a vertex to the root avoiding t would give the prohibited cycle above t. The new path has no side entrances or exits after deletion. In all subsequent logical substitutions the path as a whole stands for the single gate t with sufficient input {p}; the edges of the path are not interpreted as new gate equations. If a later graft encompasses a marked path, its root t is forced directly by the retained leaf label p. If a later cycle has highest vertex t', that vertex has two entering retained edges and hence is not an internal vertex in a marked path. Once the whole directed graph is a tree, contracting marked paths produces exactly one leaf per original point. Each remaining binary branch is an actual AND from the original D(L); the earlier minimum-witness graft argument applies with the certified singleton leaves in place.

There is also a simultaneous count for graphs with more than one cycle. In the ordinary undirected block–cut tree, take any maximal vertex-biconnected block K containing a cycle. If the root lies in K let t be the root, otherwise let t be the articulation on the block–cut path from K to the root (a non-articulation root is represented by its unique block). All directed paths from a vertex of K to the root must pass t, and the segment up to t stays inside K: a path that left K and returned would either use the same articulation twice or create another route in the block–cut tree. Hence t is the topologically latest vertex of K. Each vertex of K has degree at least two within K, so t has exactly two entering edges within K and all of its outgoing edges leave K.

No ancestor of t has a route to the root avoiding t. Such a route, paired with the route through t, would produce an undirected cycle containing one of the two entering edges in K and an outgoing edge outside K. Every cycle is part of a single maximal vertex-biconnected block, and two blocks cannot share an edge. This contradiction proves the disjoint-source graft argument for this t without any preliminary deletions. If its source set has size at least two, charge a separate anchor to this block. Distinct blocks cannot have the same exit t, as both entering edges at t would then belong to both blocks. Distinct lines have different charged exits by the unique-minimum witness. Each exit is the latest vertex of some cycle (in a vertex-biconnected block, two incident edges at t lie on a common cycle), so all such anchors in a union of line proofs are independent by the highest-vertex argument. A block with several independent cycles may still have only one exit; this argument gives only one anchor for that block.

For any nonempty family X of lines, the union of the D(L), L in X, is connected, since each pair contains the raw source at the intersection of the two lines. Write u for the number of points in their union. At most m−(13−|X|) gates occur. Since each gate has at most two incoming edges and raw sources have none, the union's cycle rank is at most m−12+|X|−u. The anchor cycles have different latest vertices, and thus give linearly independent edge vectors over F2. In a nonempty combination take the cycle whose latest vertex is highest; an edge at this vertex occurs only once among the cycles in the combination. It follows that

    m ≥ 12 + u − |X| + number of anchored lines in X.

For a pencil of four lines the union of raw points has size thirteen. Therefore every pencil contains at most m−21 anchored lines. Each anchored line is in four pencils, giving 4b ≤ 13(m−21). Together with m ≥ 39−2b this excludes m≤23. For m≤23 one has b≤6 and consequently m≥27. Thus **m≥24**.

Taking X to be just the anchored lines yields m ≥ 12 + the number of points covered by those lines, whenever at least one exists. In particular an m=24 circuit would have to miss a point in the union of its ≥8 anchored lines. At most one point can be missed, since two missed points would force seven clean lines from their two pencils. The union would have exactly twelve points, and every size inequality for X would be tight. These observations do not exclude m=24.

## Small counterexamples to per-line ownership

Run the checked script `overlap-examples.js` and see `overlaps.json`. It evaluates every output on all 1,093 possible rows and examines every gate's minimum witnesses and positive line rows. For L={0,1,3,9}, the six dual gates (0∨2), (0∨4), s=(0∨2)∧1, t=s∧3, v=(0∨4)∧9, o=t∧v compute the target on the promise. Every acceptance proof at L repeats 0. Only t and o are true exclusively on L among line rows, and only o has a unique minimum input of at least two points. Thus only two gates qualify even for either of these two criteria combined. A second nine-gate example in the same file has only its terminal qualifying. These examples implement just one line each. A line with a clean proof can also have fewer than three gates true on just its own line row; the five-gate example in the script has three gates with unique minimum supports instead.
