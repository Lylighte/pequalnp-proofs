# Hidden components when the gate budget is 25

Isolate thirteen terminal AND gates in the dual. If an output is read downstream, replacing that reference by dual false preserves all other outputs on the promised domain by positivity and the pairwise disjoint target truth sets. Normalize constants and unused gates, retaining terminals as designated outputs. Delete the terminal vertices and consider the undirected graph of the thirteen raw points and the remaining hidden gates. Each component contains a raw point. Every output has at most two operands, each contained in one component. Varying any of the four points on its line changes that output, so the partition of the raw points into hidden components must meet every projective line in at most two blocks.

hidden-components.cjs enumerates all canonical restricted-growth partitions. At the first coordinate not yet assigned it tries any existing block or one new block. It prunes only when an already partially assigned line has three colors. There are 4,226 surviving partitions: one with a single block, 4,095 with two blocks, and 130 with three blocks. None has more. The two-block count also equals (2^13−2)/2.

For a crossing line L, its terminal must have one operand in each intersecting component. The operand in component A accepts L∩A by independence from all other points. Any smaller or equal-size activating set for this operand can replace L∩A while keeping the other component's points. The combined set stays admissible and must equal L. Therefore that operand has unique minimum activating set L∩A. If this slice has at least two points it requires a hidden gate. Different slices of size at least two cannot share the same wire. The JSON records this necessary count and the connectivity count per block, not sufficiency.

With 25 total gates there are at most 12 hidden gates. For d hidden components the total cycle rank of the hidden graph is at most 12−13+d=d−1. The entire hidden graph would thus have at most two independent cycles, and would be a tree in the connected case. This result concerns only hidden gates; adding the thirteen terminal outputs can introduce further cycles. The classification has not excluded all 25-gate candidates.

The per-component counts sharpen this enumeration at 25 gates. With 12 available hidden gates, all three-block partitions require at least 14, as do all two-block partitions with a smaller block of four or more points. Only the connected case or two components with a smaller block of size 1, 2 or 3 remain. Consequently the hidden graph would have cycle rank at most one.
