# L-meta-920: exact representation on the admissible inputs

Write Z for the set of zero input coordinates. The admissible domain is |Z| ≤ 4. A wire is represented by the inclusion-minimal Z for which its value is false. The raw wire at point p has the single term {p}. An invalid read has the single empty term because it always returns false. The identically true wire has no terms. The identically false wire has just the empty term.

For an original AND, combine the two families by union and delete every strict superset of a retained term. For an original OR, take the unions A ∪ B for the two term families, discard unions of size above four and again take minimal terms. Nullary and unary gates obey the same formulas with the usual identities. Since Z ranges over a down-set, a term discarded for size cannot become feasible at a later gate. Induction on the gate order proves equivalence with Circuit.wires on every admissible row. Correctness of all outputs is equivalent to the family for each output w being exactly the one-element family containing L_w. An output index out of bounds has the false-wire family, so cannot be a valid output.

A second exact characterization is useful when the number t of original AND gates is small. Independently at every AND select one of its arguments (unary and empty handled by their identities). Replace that AND by the selected wire. The rest is an OR circuit. On the dual zero-set variables it gives one conjunction for each output and selector. For any input on which the original output is false, globally choose, at every false AND, a false child. Induction shows that on this input every original false root remains false. Conversely each selector can only enlarge the original truth value in the ordinary Boolean order, so any input it sends to false was false originally. Thus all the selectors enumerate the union of the false conditions, including with shared gates. For target L_w, at least one term must equal L_w and every term must be either exactly L_w, identically impossible, or of size at least five. This last condition forbids spurious activations on up to four zero points. With t small it avoids enumerating all 1,093 inputs for repeated candidate tests.

Reproduce the independent JavaScript cross-check from the project root with tools/node/node.exe state/plane920-core/antichains.cjs. The program checks every wire against the literal Boolean evaluator on all 1,093 allowed rows. It checks the thirteen targets of a 39-gate circuit, all 78 pair intersections and twenty deterministic 38-gate controls including invalid references, duplicates, unary gates and nullary gates. This is a verification method and a size-39 upper bound. A proof that every candidate of size at most 38 fails is still open here.
