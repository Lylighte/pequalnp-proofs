# Six selected lines with four ORs need at least ten hidden ANDs

Suppose six prescribed four-point line indicators on the full weight-at-most-four domain can be computed with at most four ORs and nine nonterminal ANDs. If there are fewer ORs, three-or-six-lines-29.md excludes the circuit. Bypassing an OR on all six positives is impossible for the same reason.

Each selected line has at most one private helper. Otherwise deleting the line and its two private helpers gives five targets, four ORs and seven helpers, excluded by five-lines-seven-helpers.md. Every genuine AND input to an OR must be true on at least two selected lines. If it were true on at most one, bypass this OR to the other input and set the helper to false. The five other outputs would remain correct using at most three ORs and eight helpers. This is excluded by three-or-six-lines-29.md. In particular every OR operand can be expressed as at most one raw point conjoined with a subset of earlier named ORs.

The first three OR functions have 1,897 symmetry classes after the restriction to operands true on at least two of the thirteen geometric positives. All six selected targets are still free to vary. For every fourth-OR pair, the full-domain three-raw-point isolation test from six-lines-28.md finds lines that could use at most one private AND. Then compute the independent per-line lower bound c from all possible shared helpers. The c values count gates private on the entire thirteen-line set, which are also private to any selected subfamily containing that line.

For a fixed decomposition of the first three function values and a physical fourth-OR input pair, charge one hidden AND per distinct required nonraw operand function not already available as a named OR. Each of these paid functions must be true on two or more selected lines. If T is the chosen six, let J range over its nonempty subfamilies. Remove one private helper for each outside line with c equal to one, and every distinct named paid function false on all of J. The two charges are disjoint. On J, a retained OR can be bypassed if either input's accepted rows are contained in the other's. For the fourth OR the physical input pair is known. For each of the first three the preliminary test only uses the weaker upper bound that at least two rows of J satisfy the OR; in the final library test an even weaker upper bound permits one accepted row. Granting a larger surviving OR count is safe.

On J use the checked one-, two- and three-line free-OR bounds 2, 4 and 5. The free-OR six-line bound is six by ../plane920-math/partial-helper-proof.md. With at most four ORs the five- and six-line bounds are eight and nine from five-lines-seven-helpers.md and six-lines-28.md. With at most three ORs the bound for n in {3,4,5,6} is 2n−1, from the three-target free bound, the four-target restoration, and the new five-/six-target lemmas. At most one OR requires 2n hidden ANDs. The initial estimates can be weakened wherever convenient without affecting soundness.

The final paid-library check grants the charged physical functions as free boundary wires and enumerates optional shared functions grouped by their exact positive set on all thirteen lines. It then charges private gate needs beyond these free wires. For each J, paid or optional shared gates absent on J can be deleted. Every private charge outside J can separately be deleted. The selected-family check includes the cap of one private gate at each target. It is safe to combine distinct fourth-arm descriptions with equal truth functions on the promise only when subsequent tests depend solely on those truth functions. fast-four-nine.cjs tests the actual fourth operand pair separately for each charged-prefix decomposition.

The complete run enumerated 1,675,184 fourth-OR arm pairs. Of these 1,477,787 were positively incomparable. The preliminary isolation test retained 163,491 pairs after removing duplicate or already named ORs. There were 167,291 conservative prefix fee computations, 119,762 surviving weak six-line family choices, and 7,661 full paid-library tests. No family survived. Node took 75.3 seconds.
